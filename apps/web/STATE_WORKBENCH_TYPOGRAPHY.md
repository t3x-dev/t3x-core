# T3X State Workbench 字号与行高规范

状态：当前基线
更新日期：2026-09-01
适用范围：`apps/web` 的 Project Shell、State 工具栏、关系侧栏、State 树、右侧变更审计栏与 Code 视图。

这份文件是 State 工作台字号、行高和控件高度的单一对照表。后续调整应先修改本文件中的角色规格，再同步代码；不要在组件里继续增加零散的 `12.5px`、`13.5px` 或仅为某一行存在的字号。

## 1. 字体

| 用途 | 字体 | 使用范围 |
| --- | --- | --- |
| 产品界面 | Geist Sans | 导航、标题、树节点、说明文字、按钮、状态 |
| 技术信息 | Geist Mono | 路径、分支、Hash、代码、机器值、机器节点名 |

规则：

- 自然语言、标题和普通节点使用 Sans，不因包含下划线就把整列都变成等宽字体。
- 路径、Hash、代码和需要逐字符核对的值使用 Mono。
- 用户可见正文不得小于 `12px`；需要阅读或可能换行的文字不得小于 `13px`。
- 时间和空值可以使用斜体；删除内容不使用删除线，依靠红色语义、行底色、侧边条和 `REMOVE` 标识表达。

## 2. 全局字号梯度

| Token | 字号 | 推荐行高 | 角色 |
| --- | ---: | ---: | --- |
| `text-xs` | 12px | 16–18px | 时间、路径、状态、辅助元数据、紧凑 Badge |
| `text-sm` | 13px | 18–20px | 默认内容、树叶节点、说明、按钮、输入框 |
| `text-base` | 14px | 20px | 一级导航、根节点、重要标签 |
| `text-md` | 15px | 22px | 强调正文，谨慎使用 |
| `text-lg` | 16px | 24px | 面板标题、编辑任务标题 |
| `text-xl` | 18px | 28px | 当前选中节点等局部主标题 |
| `text-2xl` | 20px | 28–30px | 页面级标题，State 工作台通常不用 |
| `text-3xl` | 24px | 32px | 展示型标题，工作台内禁用 |

Project 工作台固定使用 `12 / 13 / 14 / 16 / 18px` 五档。全局 Compact 模式不得把该页面的 `text-xs` 和 `text-sm` 压到 `10px`、`11px`。

## 3. 字重

| 字重 | 角色 |
| ---: | --- |
| 400 | 正文、值、说明、时间 |
| 500 | 叶节点、机器节点、普通按钮、字段标签 |
| 600 | 根节点、分组标题、面板标题、主要操作、状态 Badge |
| 700–800 | 只保留给品牌字标，不用于普通内容层级 |

不要通过“所有标题都加粗”建立层级。层级由字号、字重、颜色、缩进、留白共同完成。

## 7. State 树

### 7.1 行高与结构

| 行类型 | 行高 | 文字规格 |
| --- | ---: | --- |
| 根节点 / 可展开分组 | 36px | 见下表 |
| 叶节点 | 34px | 13px / 20px |
| Chevron 槽位 | 20px | 图标 14px |
| 每级缩进 | 16px | — |
| Badge | 20px | 12px / 16px |

默认密度不再继续压缩。`36 / 34px` 已经接近在 20px 图标槽、20px Badge 和可点击性的共同约束下的下限。若以后提供显式 Compact 模式，可以试验 `34 / 32px`，但不能作为默认值。

### 7.2 第一列：节点

| 节点角色 | 字号 / 行高 | 字重 | 字体 / 颜色 |
| --- | --- | ---: | --- |
| 根节点 | 14px / 20px | 600 | Sans，主文字色 |
| 一级分组 | 14px / 20px | 600 | Sans，主文字色 |
| 深层分组 | 13px / 20px | 600 | Sans，主文字色 |
| 叶节点 | 13px / 20px | 500 | Sans，次级文字色 |
| 机器节点 | 13px / 20px | 500 | Mono；分组用主文字色，叶节点用次级文字色 |

### 7.3 第二至第四列

| 列 | 内容角色 | 字号 / 行高 | 字重与样式 |
| --- | --- | --- | --- |
| Value | 普通值 | 13px / 20px | 400，长文本 Sans，原子值 Mono，不加框 |
| Value | `empty` | 12px / 20px | 400，斜体、三级文字色 |
| Value | Missing | 12px / 16px | 600，20px 状态 Badge |
| Effect | ADD / REMOVE / SET | 12px / 16px | 600，20px 操作 Badge |
| Effect | 原因说明 | 12px / 18px | 400，次级文字色 |
| Changed | 相对时间 | 12px / 16px | 400，斜体、右对齐、tabular nums |

列角色必须有辨识度：值列负责“读值”，操作列负责“扫动作”，时间列只做弱提示。不能让后三列都使用同样的字号、字重和颜色。

## 8. 右侧变更审计栏

推荐宽度为 `340px`；内容必须在该宽度下仍然可读，不依赖极小字号塞入更多字段。

| 元素 | 字号 / 行高 | 字重 / 样式 |
| --- | --- | --- |
| Selected change / 类型 | 12px / 16px | 600，大写、三级文字色 / 语义色 |
| 当前节点名称 | 18px / 28px | 600，面板主标题 |
| 原值 → 新值 | 13px / 20px | 400，Mono；不使用删除线 |
| Why / Source / Verified 等段标题 | 13px / 20px | 600，Sans |
| 解释正文 | 13px / 20px | 400，Sans |
| Source 名称 | 13px / 20px | 500–600，Mono |
| Source 摘要 | 12px / 18px | 400，Mono |
| Check 摘要 | 13px / 20px | 400；失败标题 600 |
| Check 细节 | 12px / 18px | 400 |
| 作者 / Commit / 时间 | 12px / 18px | 400，技术值使用 Mono |
| Technical details 行 | 13px / 20px | 400；操作 500，最小高度 40px |
| 底部操作按钮 | 13px / 20px | 600，高度 32px |

右栏的节点名称是局部主标题，必须明显大于段标题和正文。段标题靠 `13px + 600` 建立层级，不使用过小的全大写字母堆出“高级感”。

## 10. 实施约束

1. 一个组件内最多使用三档字号；需要更多层级时优先调整颜色、字重和间距。
2. 不新增半像素字号；使用本规范已有档位。
3. 12px 只用于单行辅助信息。任何需要理解、比较或换行的内容使用 13px 及以上。
4. 行高不得只为填满空白而放大。节点少造成的空白应保留，不靠松散行高补齐。
5. Badge 高度统一为 20px；普通紧凑控件为 28px；主要输入和底部操作为 32px。
6. 日期可斜体并变淡；正文不斜体；删除内容不加删除线。
7. 标题和内容不能同字号、同字重、同颜色三项全部相同。
8. 默认 State 树维持 `36px` 分组行和 `34px` 叶行，除非经过完整页面截图对比后重新修订本规范。
